# 🎓 Ace It Up | The Premium Placement Preparation Platform

![Ace It Up Banner](https://images.unsplash.com/photo-1522202176988-66273c2fd55f?auto=format&fit=crop&q=80&w=1200&h=400)

**Ace It Up** is a state-of-the-art, AI-powered learning management system designed to bridge the gap between academic learning and corporate placement success. Built for students who demand a premium, high-performance preparation experience.

---

## 🚀 Core Features

### 🧠 Intelligent Practice Hub
*   **Adaptive Aptitude Modules:** Dynamic question scaling based on your performance.
*   **AI Interview Simulations:** Practice with industry-specific behavioral and technical questions using the STAR method.
*   **Real-time Communication Training:** AI-driven analysis of your speaking fluency, clarity, and confidence.
*   **Professional Writing Suite:** Master business correspondence with our AI Email Etiquette analyzer.

### 📈 Analytics & Progression
*   **Smart Insights:** Detailed breakdown of your strengths and weaknesses across all modules.
*   **Global Leaderboard:** Compete with peers and climb the ranks with our gamified XP system.
*   **Dynamic Roadmaps:** Personalized learning paths that adapt as you improve.
*   **Interactive Resume Builder:** Create ATS-friendly, professional resumes in minutes.

### 📱 Premium UX/UI
*   **Glassmorphic Design:** A sleek, modern aesthetic with smooth animations and dark mode support.
*   **100% Responsive:** Seamlessly transition from your desktop at home to your mobile device on the go.
*   **AI Mentor:** 24/7 access to our intelligent assistant for instant guidance.

## 🛠️ Tech Stack

*   **Frontend:** React 19 + TypeScript + Vite
*   **Styling:** Tailwind CSS + Framer Motion (for high-end animations)
*   **Backend:** Supabase (Realtime Database & Authentication)
*   **Deployment:** Vercel (Production-grade hosting)
*   **Icons:** Lucide React

## ⚙️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/codebysakshi05/ace-your-prep.git
   cd ace-your-prep/FRONTEND
   ```

2. **Install dependencies:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Configure Environment Variables:**
   Create a `.env.local` file in the `FRONTEND` directory and add your Supabase credentials:
   ```env
   VITE_SUPABASE_URL=your_project_url
   VITE_SUPABASE_ANON_KEY=your_anon_key
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```
